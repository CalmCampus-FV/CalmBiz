# CalmBiz

[![CI](https://github.com/CalmCampus-FV/CalmBiz/actions/workflows/ci.yml/badge.svg)](https://github.com/CalmCampus-FV/CalmBiz/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Company demos and prototypes for **CalmCampus**, a weekly wellbeing check-in that takes less than a minute and keeps every answer on the phone. This repository is for staff wellbeing demos aimed at employers. There are no company demos yet.

> We are students, not medical professionals. CalmCampus does not diagnose or treat. If you need help, we strongly suggest a doctor, your occupational health service or another support service. If you are in crisis, contact your local emergency number or a crisis line.

## What's here

| Path | What it is |
|---|---|
| [`demos/`](demos/) | One folder per company demo (none yet), plus the root landing page published to GitHub Pages |
| [`scripts/check-demos.py`](scripts/check-demos.py) | The check CI runs on every demo |

Rules for demos and wording are in [AGENTS.md](AGENTS.md).

## Where it runs

`demos/` is published as this repo's own GitHub Pages site on every push to `main`: live at [biz.calmcampus.app](https://biz.calmcampus.app/) (HTTPS enforced; `calmcampus-fv.github.io/CalmBiz/` redirects there).
