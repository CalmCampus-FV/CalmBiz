# Company demos

Each company demo gets its own folder here, `demos/<id>/` (the files at the root of `demos/` are the landing page and the planned domain), with an `index.html` and everything it needs (no files from outside the folder, nothing loaded from other hosts).

There are no company demos yet. Do not add placeholder companies, logos, quotes or numbers: a folder is created only for a real demo that Florian or Hélène asked for.
